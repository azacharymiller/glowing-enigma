# Steeplechase Results Archive

Every American steeplechase start we could find, 1966-2026:
150,423 starts across 4,901 meets.

- `index.html` - the searchable archive (demo of a redesigned Central Entry Office site)
- `data/archive.json.gz` - the full data set, gzipped JSON; download and use freely

Updated automatically each week. Every update is kept in this repository's history.
